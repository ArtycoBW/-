# Разряд

Платформа прямого найма по подтверждённым навыкам. Решение специального трека Федерации спортивного программирования на ЛЦТ 2026.

**Основной путь:** специалист заполняет профиль → подтверждает выбранный грейд тестом → компания находит его в нужной категории → отправляет предложение с зарплатой → специалист принимает → контакт открывается только этой компании.

В дополнение работают вакансии, самостоятельные отклики, практические задания с проверкой работодателем, импорт текстового PDF-резюме и экспорт профиля в PDF. Интерфейс на русском языке, адаптирован для телефона. Лендинг основан на предоставленном шаблоне Relay / GetLayers.

## Быстрый запуск в Windows

Нужны Node.js 24+ и uv. Из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start-local.ps1
```

Открыть <http://localhost:3000>. API: <http://localhost:8000/api/v1/docs>. Процессы запускаются скрыто, логи и PID находятся в `.local/`. Повторный запуск при занятых портах останавливается с объяснением, существующие процессы не завершаются автоматически.

Ручной запуск, в двух терминалах:

```powershell
uv python install 3.12
uv venv --python 3.12 .venv
uv pip install -r backend/requirements.txt
$env:DEMO_MODE='true'
.venv\Scripts\python.exe -m backend.seed
.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

```powershell
cd frontend
npm ci
npm run dev
```

Для Linux/macOS: создать venv через `python3 -m venv .venv`, установить requirements, выставить `DEMO_MODE=true`, использовать `.venv/bin/python`. Frontend запускается теми же npm-командами.

## Запуск в Docker

Остановить локальный frontend на порту 3000 перед запуском web-контейнера.

```sh
docker compose up --build -d
docker compose exec api python -m backend.seed
```

Интерфейс: <http://localhost:3000>. Почтовый ящик Mailpit: <http://localhost:8025>. Swagger доступен через тот же origin: <http://localhost:3000/api/v1/docs>. PostgreSQL хранит данные в именованном volume `database` и не публикуется на хост. `docker compose down` останавливает сервисы, сохраняя данные; удаление volume уничтожит данные и для обычного перезапуска не нужно.

Это конфигурация **локального демо**, не публичного размещения. Пароль БД в `.env.example` демонстрационный. Перед внешним размещением нужны собственные секреты, HTTPS, отключённый демовход, реальная доставка почты и процедуры эксплуатации из документации.

## Демонстрация

На странице входа есть кнопки двух ролей. Стартовый набор: 36 синтетических специалистов, 2 компании, 6 вакансий, потребности, задачи и входящее приглашение. `backend.seed` идемпотентен.

| Роль | Почта | Пароль |
|---|---|---|
| Специалист | candidate@demo.razryad.ru | RazryadDemo2026! |
| Работодатель | employer@demo.razryad.ru | RazryadDemo2026! |
| Вторая компания для проверки доступа | team@demo.razryad.ru | RazryadDemo2026! |

Демовход и ссылка на письмо в интерфейсе включаются только при `DEMO_MODE=true`. Без SMTP в этом режиме письма сохраняются в `.local/mail`; в Docker письма доставляются в Mailpit. Для полного пути нового специалиста зарегистрируйте новый аккаунт, подтвердите адрес, заполните навыки и согласия, пройдите тест.

История ФСП — **демореестр**, а не официальная верификация. Официальный API организатором не предоставлен. ID `DEMO-FSP-2026` привязывается к одному аккаунту. Профиль без достижений полностью поддерживается. Название продукта не означает присвоение спортивного разряда.

## Проверки и обучение

```powershell
.venv\Scripts\python.exe -m pytest tests -q
.venv\Scripts\python.exe -m ml.train
cd frontend
npm run lint
npm run typecheck
npm run build
npm run test:e2e
```

Браузерные тесты требуют работающих локальных API/frontend, Chrome и демонстрационного режима. Они создают синтетический аккаунт `e2e…@example.org` в локальной базе. Для проверки успешного теста доверенная тестовая фикстура читает ответы напрямую из локальной SQLite: публичный API правильные ответы не раскрывает. Тесты API используют отдельную `.local/test.db` и очищают только её.

Для браузерных тестов Docker-стенда установить `E2E_DATABASE=postgres`: доверенная фикстура читает ответы через `docker compose exec api`. Для замера задержки: `.venv/Scripts/python.exe scripts/benchmark.py`. Он работает только в деморежиме, записывает агрегаты без персональных данных в `docs/performance.json`. Последний прогон: 25 серверных тестов и 3 E2E успешны; p95 подбора 684 мс при 10 одновременных запросах на малом демонаборе.

Обучение использует только CPU, фиксированный seed и независимые синтетические разбиения. Результаты: `ml/model.json`, `ml/metrics.json`. Модель экспортируется в безопасный JSON; pickle не загружается. При отсутствии модели подбор работает по формуле. Балл не является вероятностью трудоустройства.

## Структура

```text
backend/    FastAPI, доменные правила, SQLAlchemy, PDF и демоданные
frontend/   Next.js, Tailwind, Relay-лендинг и рабочие кабинеты
ml/         генератор синтетики, обучение, модель и метрики
tests/      серверные и алгоритмические проверки
docs/       русская техническая документация и OpenAPI
scripts/    локальный запуск и подготовка материалов
output/     материалы защиты
```

В Git не включаются секреты, локальные БД, исходные архивы, экспорт переписки, зависимости, кэши и служебные инструкции разработки. Лицензии и происхождение компонентов перечислены в [THIRD_PARTY.md](THIRD_PARTY.md).
