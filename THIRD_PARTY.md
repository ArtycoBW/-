# Сторонние компоненты

Лендинг адаптирован из предоставленного архива Relay (GetLayers). Сохранены композиция, spring-анимации и декоративная сцена. Исходная лицензия шаблона сохранена в `frontend/LICENSE.md`. Справочная страница: https://www.getlayers.ai/?layer=relay. Тексты, назначение блоков и интерфейсы кабинетов изменены под «Разряд».

Изображения лиц из шаблона используются только в явно подписанных декоративных демопримерах. Это не отзывы пользователей и не подтверждение партнёрства. Стартовые компании, вакансии и специалисты придуманы для демонстрации.

Презентация использует предоставленный организаторами шаблон ЛЦТ 2026. Логотипы в нём принадлежат соответствующим правообладателям. Слайды 7–11 исходного файла используются как обязательные формы. Разрешение организатора на использование брендбука опубликовано в группе спецтрека 7 октября 2026 года.

Основные зависимости: Next.js (MIT), React (MIT), Tailwind CSS (MIT), Three.js (MIT), react-spring (MIT), Lenis (MIT), FastAPI (MIT), SQLAlchemy (MIT), scikit-learn (BSD-3-Clause), NumPy (BSD-3-Clause), SciPy (BSD-3-Clause), pypdf (BSD-3-Clause), ReportLab (BSD), PostgreSQL (PostgreSQL License), Mailpit (MIT). Полные тексты лицензий находятся в дистрибутивах соответствующих пакетов. Точные версии фиксируются в `frontend/package-lock.json` и `backend/requirements.txt`.

Шрифты интерфейса: Inter, Lora, JetBrains Mono, получаемые через next/font. Тексты SIL Open Font License из репозитория google/fonts сохранены в `licenses/fonts/` и включаются в runtime-образ. Презентация сохраняет Montserrat из шаблона.
