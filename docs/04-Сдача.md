## Регламент

Промежуточный дедлайн: **11 октября 2026 года, 23:59 по Москве**. Сообщение модератора от 10 октября подтверждает дату; сообщения о «сегодня» не меняют её.

Для промежуточной сдачи нужны ссылка на публичный репозиторий, презентация и развёрнутое демо. Если демо недоступно, нужна запись. Сопроводительная документация должна быть в PDF; во время работы допустим Markdown с последующей конвертацией. Презентация нужна уже к промежуточной сдаче. В ответах XLSX указан регламент выступления 10 минут.

Важное уточнение от 7 октября: **слайды 7–11 исходного шаблона обязательны, их дизайн и структура сохраняются**. В рабочей презентации они перенесены в начало. Остальные слайды можно оформлять по усмотрению команды. Веб-интерфейс Git не обязателен, но эксперты должны иметь возможность получить и посмотреть код. В более позднем сообщении организатор прямо требует публичный репозиторий для любого сервиса.

Ссылки загружает капитан через личный кабинет платформы на странице задачи. Отправка в Telegram не является сдачей.

## Проверка перед отправкой

- Код клонируется по публичному URL; README соответствует текущему состоянию.
- Ссылки открываются в приватном окне браузера.
- Демодоступ работает и явно обозначен как демонстрационный.
- Презентация не содержит незаполненных сведений о команде.
- PDF скачивается и содержит архитектуру, алгоритмы, методику, результаты и запуск.
- Запись показывает реальный продукт и основной сценарий, а не только лендинг.
- Исходная переписка, персональные данные пользователей платформы, пароли окружения и локальные данные в репозитории отсутствуют. Контакт капитана опубликован в материалах защиты по его указанию.
