# Постоянный домен без остановки временного адреса

Состояние на 11 октября 2026: https://razryad.agropulseai.ru работает, подтверждение почты и восстановление пароля включены. Инструкция ниже описывает действующее развёртывание и его воспроизведение.

Адрес: `https://razryad.agropulseai.ru`.

`compose.domain.yml` — отдельный проект `razryad-domain`. Он использует существующие образы приложения и общую PostgreSQL, но отдельные API и frontend. Это позволяет разрешить новый Origin без перезапуска действующего API. Сетевой псевдоним `api` существует только в отдельной сети нового входа и не меняет маршрутизацию старого frontend.

## Подготовка

В `.local/domain.env` сохраняются `DOMAIN_API_IMAGE` и `DOMAIN_WEB_IMAGE` (ID проверенных Docker-образов). В `.local/domain-api.env` — настройки действующего API с новым `PUBLIC_ORIGIN=https://razryad.agropulseai.ru`, `COOKIE_SECURE=true`, `TRUST_CLOUDFLARE=true`. В `DATABASE_URL` адресом существующей БД должен быть `razryad-db-1`, для почты используется `SMTP_HOST=smtp.timeweb.ru`, порт 587 и STARTTLS; подробности — в разделе «Почта и домен». Эти файлы содержат локальные настройки и исключены из Git.

Запуск параллельного приложения:

```powershell
./scripts/start-domain-tunnel.ps1 -PrepareOnly
```

Проверка готовности: `http://127.0.0.1:3001/api/v1/ready`. Вход в локальном HTTP не предназначен для использования: cookies требуют HTTPS.

## Cloudflare

1. DNS-зона agropulseai.ru активна: NS brodie.ns.cloudflare.com и rosalie.ns.cloudflare.com. При повторной настройке сохранять записи основного сайта и почты; A-записи основного сайта оставить DNS only.
2. Создать отдельный remotely-managed Cloudflared Tunnel `razryad`.
3. Сохранить только токен подключения из команды установки в `.local/cloudflare-tunnel-token.txt`. Не публиковать его в переписке, Git или скриншотах.
4. Запустить `./scripts/start-domain-tunnel.ps1`.
5. Создать Published application route: поддомен `razryad`, домен `agropulseai.ru`, сервис HTTP, URL `domain-web:3000`, путь пустой.
6. Проверить статус Healthy, HTTPS, ready, вход и получение профиля. Проверить также исходный временный адрес.

Не выполнять `docker compose down` для исходного проекта, не запускать `scripts/start-tunnel.ps1` для настройки домена и не менять его `.local/tunnel.env`.

## Работа и ограничения

Политика `unless-stopped` перезапускает контейнеры после сбоя и запуска Docker, если их не останавливали вручную. Для восстановления после перезагрузки ПК отдельно требуется автозапуск Docker Desktop. Сон, отключённый ПК или отсутствие интернета делают локальный сайт недоступным. Именованный туннель сохраняет идентификатор и адрес, но не гарантирует отсутствие сетевых сбоев.

Оба адреса используют общие аккаунты и данные, но cookies браузера для разных доменов независимы: на новом адресе нужно войти повторно. В доменном API версии 1.3 лимиты запросов сохраняются в PostgreSQL. Старый API не пересоздаётся и сохраняет поведение своего выпуска. Эта конфигурация предназначена для перехода без остановки.
