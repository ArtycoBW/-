# Как проверить «Разряд»

Текущий стенд: https://especially-eng-finally-walt.trycloudflare.com — временный адрес Cloudflare. Постоянная точка входа в код и инструкции: https://github.com/ArtycoBW/-

Интерфейс работает на русском. Новый пользователь входит сразу после регистрации: подтверждение почты отключено. Cloudflare предоставляет HTTPS и маршрут к приложению, но не проверяет владение электронной почтой.

## Подготовка

Откройте стенд в двух разных профилях браузера или в обычном и приватном окнах. Так сессии специалиста и компании не заменят друг друга. Начальные профили, компании, достижения и вакансии демонстрационные, с реалистичными описаниями. Это не реальные персональные данные и не действующие предложения о работе.

Демоаккаунты общие: действия другого посетителя могут изменить их состояние. Для чистого сценария зарегистрируйте отдельные аккаунты. Никогда не вводите в публичное демо чужие контакты, документы или рабочие пароли.

## 1. Лендинг и регистрация

1. Откройте главную при масштабе браузера 100%. На широком экране композиция компактнее; заголовок и основные кнопки видны без изменения масштаба.
2. Прокрутите до карточки приглашения: сообщение, зарплата и кнопки не пересекаются. В блоке приватности читаются состояния доступа, нет `NaN`. Подпись результата теста помещается внутри виджета.
3. Проверьте страницу входа на телефоне и компьютере. При настройке ОС «уменьшение движения» фон становится статичным.
4. Создайте специалиста с новой почтой и паролем от 10 символов. Дайте согласие. Ожидается немедленный переход в кабинет, без письма.
5. Выйдите и войдите с теми же данными. Неверный пароль выдаёт понятную ошибку. Кнопка с глазом показывает и скрывает пароль.

## 2. Профиль и тест

1. У нового специалиста заполните город, стек, опыт, зарплату и контакт. Включите публикацию и сохраните. Перезагрузите страницу: данные сохранены.
2. До прохождения теста компания не должна находить профиль в банке подтверждённых специалистов.
3. Выберите специализацию и грейд. Начните тест, ответьте на несколько вопросов, сохраните черновик и обновите страницу. Ответы и оставшееся время сохраняются.
4. Завершите тест. При 70 баллах и выше категория подтверждается; при неуспехе можно выбрать другую категорию по правилам интервалов. Повторная отправка не должна менять уже рассчитанный результат.
5. Скачайте PDF-профиль. Текст на русском, результаты и достижения соответствуют кабинету.

## 3. Подбор и приватность

1. Войдите компанией «Контур Лаб». Откройте «Найти специалистов». Создайте потребность: backend, middle, Python/FastAPI/PostgreSQL, удалённо, 180–260 тыс. рублей.
2. В подборке должны остаться специалисты выбранной категории. Откройте объяснение балла: совпавшие и недостающие навыки, тест, активность, вклад ФСП. Балл не называется вероятностью найма.
3. Откройте Александра Волкова: его личный контакт скрыт. Отправьте приглашение с зарплатой и контактом компании.
4. В окне специалиста проверьте условия и примите приглашение. Только теперь «Контур Лаб» видит контакт.
5. В третьем окне войдите «Север Технологии». Контакт этого специалиста должен оставаться закрытым, пока он отдельно не согласится этой компании. Если ранее уже принималось её стартовое предложение, используйте нового специалиста.
6. Отклоните другое предложение. Условия и история остаются доступны, новый доступ к контактам не появляется.
7. Отзовите разрешение в профиле специалиста. Обновите страницу компании: контакт снова скрыт.

## 4. Вакансии, отклики и практика

1. Создайте вакансию от компании. Проверьте в списке специалиста фильтры по направлению и грейду.
2. Откликнитесь с сопроводительным текстом и отдельным согласием на контакт. Повторный отклик на ту же вакансию не создаёт дубликат.
3. Компания читает отклик и меняет статус. Специалист видит обновление.
4. Создайте практическую задачу с критериями. Специалист отправляет решение. Компания ставит оценку и обратную связь. Она видна автору решения.
5. Архивируйте вакансию. Она исчезает из доступных для новых откликов; история сохраняется.

## 5. Негативные сценарии

- Зарплата «от» больше «до»: сервер отклоняет запись, форма показывает ошибку.
- Публикация без согласия: сервер отклоняет действие.
- Кандидат открывает URL раздела работодателя: нет доступа к функциям компании.
- Изменение чужого ID приглашения/попытки: отказ без выдачи чужих данных.
- Потеря соединения: сообщение об ошибке; после восстановления запрос можно повторить.
- Истекшая сессия: переход на вход; пароли и сессионные токены не появляются в URL.
- Почтовые маршруты без настройки: отключены; ссылки сброса пароля публичный API не выдаёт.

## Автоматические проверки

```powershell
.venv/Scripts/python.exe -m pytest tests -q
.venv/Scripts/python.exe -m ml.evaluate_robustness
cd frontend
npm run lint
npm run typecheck
npm run build
$env:E2E_DATABASE='postgres'
npm run test:e2e
```

E2E создаёт собственный профиль в БД стенда. Правильные ответы тест получает через доверенный доступ к локальной БД; публичный API их не раскрывает. Для проверки навыков живого пользователя эти подсказки не используются.

Когда включён Cloudflare, перед `npm run test:e2e` в каталоге frontend задайте `$env:PLAYWRIGHT_BASE_URL=(Get-Content ../.local/public-url.txt -Raw).Trim()`. Проверки пойдут через HTTPS. Для локального режима адрес по умолчанию — `http://localhost:3000`; он должен совпадать с `PUBLIC_ORIGIN`, а `COOKIE_SECURE` должен быть false. Одновременно смешивать локальный HTTP-вход и публичный HTTPS-вход с разными origin не следует. Скрипт записи демонстрации тоже поддерживает переменную `PLAYWRIGHT_BASE_URL`.
